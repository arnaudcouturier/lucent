# Lucent 0.3.0-beta.5

Visual polish only — nothing about how Lucent deploys, repairs or reads the game folder changed.

- **Buttons and selection cleaned up.** Primary buttons (Launch XIV, Continue, Reset setup…) are now an accent outline instead of a solid orange fill, which had drifted to carrying a hover glow and lift the design had explicitly ruled out. Six slightly different selection treatments (profiles, DLSS presets, segmented choices, settings radios, the launcher picker, Logs' tabs) are now one consistent neutral-fill-plus-accent-ring language, replacing a muddy accent-tint wash. A disabled primary or danger button now falls back to the plain secondary surface instead of a dimmed, desaturated orange or red.
- **The brand mark is redrawn.** The flat 2D crystal (the rail, the site, the taskbar icon, the favicon) is a single clean silhouette with a smooth gradient, oriented with its long spike up top to match the real 3D crystal's own proportions — replacing a shape that, with its most recent facet line, read as a kite rather than a gem.
- **The site matches**: its own buttons dropped a chunky "pressed 3D edge" look for flat pills, and its card radius tightened slightly.

## Validation — 2026-10-15

- TypeScript: 696 tests passed. Rust: 54 passed, 2 ignored (unrelated to this change). `npm run typecheck` clean on both the local candidate build and the release workflow.
- Nothing here touches deployment, config or GPU-tier logic, so this skips the RTX 4090 manual checklist; checked instead by eye across the app's `?gallery` states and the site, at mobile, desktop and ultra-wide widths.
