# Lucent 1.0.0

- **Lucent 1.0.0 is the first stable release.** The app is 0.3.0-beta.10 with a new version number, so nothing in it has moved. If you were on a beta, you keep your setup and your channel setting.
- **Stable and Beta stay two channels.** Settings → Beta channel decides which content versions Lucent offers you, and the Beta ones are the newest.

## Validation — 2026-10-23

- TypeScript: 1211 tests passed, `npm run typecheck` clean.
- Rust: 93 tests passed (3 ignored) with `--locked`.
- The release build (x64) succeeds and the exe reports 1.0.0. The source differs from 0.3.0-beta.10 only in the version strings.
- The RTX 4090 manual checklist has not been run for this version yet, and nothing here was played in game.
