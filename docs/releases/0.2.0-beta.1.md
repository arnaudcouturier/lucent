# Lucent 0.2.0-beta.1

Lucent writes a tested baseline once, then leaves config tuning to the player's in-game overlays.

- Home keeps Launch XIV, deployment status and Enabled. Opening Lucent or launching XIV no longer rewrites config settings.
- The first-install choices offer the performance profile, frame generation and HDR where supported.
- **Settings → Reset setup…** offers those choices again, backs up the current files to the displayed readable folder, and rewrites the baseline. Tier switching uses the same flow; Disabled persists.
- Content updates keep configs by default, add only absent keys, or back up and replace a config as the content version declares. Rollback restores journaled config backups without losing newer player tuning.
- Repair rebuilds missing or unreadable configs, while existing readable configs keep their contents. Older 0.1.1 deployment records migrate without changing game files.

Beta content **2026.10.15** requires this app. It targets RTX 30/40 and keeps RTX 30 XeFG multi-frame unlocks deferred. Existing configs retain their values during an update; Reset applies the new baseline and choices.
