# Lucent 0.3.0-beta.7

- **The RTX 30/40 tier is now RTX 20/30/40.** One set of game files covers the three generations, so the tier id `rtx-30-40` becomes `rtx-20-30-40` in every published content version, and the separate RTX 20 tier is gone. There is no migration: a deployment recorded under the old id stops getting update announcements, so uninstall it, or move its record aside, before moving to this version.
- **An update puts back the game's own file when it stops deploying one it replaced.** Content 2026.10.19 no longer replaces the root `nvngx_dlss.dll`. Before, an update that dropped such a file deleted it and left the game folder without its own copy until Uninstall. Now the update restores the original, through the journal, so Uninstall still ends where it started. A file a setup takeover removed first, such as an old ReShade `dxgi.dll`, is still deleted: it was removed because it conflicts.
- **Credits** name OptiScaler-FFXIV as the OptiScaler source.
- **Mods:** the Core plugins switch has a gap above the plugin list.

Content 2026.10.19 requires this app version.

## Validation — 2026-10-19

- TypeScript: 843 tests passed, `npm run typecheck` clean, and both the app and the site build. The release workflow ran both complete test suites, Rust included, before it built.
- The restore-original behaviour has tests for an original that was replaced and then dropped, a file Lucent created and then dropped, a rollback onto the restored file, a second update after it, Uninstall with and without "put my earlier files back", and the takeover case that must still delete.
- The RTX 4090 manual checklist has not been run for this version.
