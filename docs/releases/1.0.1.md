# Lucent 1.0.1

- **Settings shows where your backups are.** Settings → Game folder has a Backups row with the folder's path and an Open folder button, whenever Lucent holds copies of files it replaced. You no longer need the website to find it.
- **Nothing else changed.** The setup, the content and every other screen are as they were in 1.0.0.

## Validation — 2026-10-24

- TypeScript: 1218 tests passed, `npm run typecheck` clean.
- Rust: 93 tests passed (3 ignored) with `--locked`, run with XIV closed.
- The Backups row is covered by six new tests: hidden before any copy and after a first install over a vanilla game, shown after an install over an existing setup and for a Reset's copy, gone after an Uninstall that puts the files back. After a vanilla Uninstall the app is back on Scan, where Settings isn't reachable; the notice there gives the path.
- On the RTX 4090 machine, with the 1.0.1 release build (it reports Lucent 1.0.1) running next to the installed Lucent and a throwaway `Backups` folder in its data folder: the row appeared, its Open folder button opened File Explorer on `%LOCALAPPDATA%\Lucent\Backups` with no error, and the data folder was left as before afterwards (the update-check time and the log aside).
- First install, then Uninstall, with the 1.0.1 exe in scratch `LOCALAPPDATA` and `APPDATA` folders and a dummy game folder holding a `winmm.dll`, a `ReShade.ini` and a preset of its own (content 2026.10.27, from the cache). Scan named the backup folder before the install. The install backed up both files, and the copies in `Backups\<game folder name>\game` matched the originals by SHA-256. Settings showed the Backups row and Open folder opened it. Uninstall with "Put my earlier files back" removed `Backups`, and the game folder matched a SHA-256 listing taken before the install, file for file. The Uninstall, Run, GPU preference and app ID registry keys were unchanged, since Start menu was unticked and HDR set to Off.
- Not rerun for this release, since the app source differs from 1.0.0 only in `core.ts`, `MainScreens.tsx` and `app.css` (the Backups row), plus its tests, the site guide, the docs and the version strings: the update, Reset, drift, XIVLauncher, window-chrome and Windows 10 checks of the release checklist. The install and uninstall pass above used a dummy game folder, not the real game.
