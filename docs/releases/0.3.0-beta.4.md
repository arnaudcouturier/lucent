# Lucent 0.3.0-beta.4

- **Uninstall asks what to do with your backed-up files.** If Lucent replaced files in your game folder when it installed (an old mod setup, a swapped DLSS DLL), Settings → Uninstall now offers two choices: **Put my earlier files back** (the default, as before) or **Restore the game to vanilla**, which removes everything Lucent added and leaves those files out. Vanilla keeps their copies in Lucent's backup folder and the notice says where. With nothing replaced there is no question.
- The choice is stored, so an interrupted uninstall finishes the same way at the next start.

No content change; content 2026.10.17 works unchanged.
