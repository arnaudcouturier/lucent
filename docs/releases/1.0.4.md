# Lucent 1.0.4

- **Settings has a Troubleshooting group with a Record frame generation switch, off by default.**
  - It sets `[FramePacing] FgRecorder` in `OptiScaler.ini` in place (`true` when on, `false` when switched off again) and nothing else, through the journal. It takes effect the next time XIV starts.
  - OptiScaler-FFXIV then writes what frame generation does to `fg-recordings` in the game folder, for a bug report: only while frame generation runs, up to 144 MB a play session, the last five sessions kept.
  - Unlike the Game patches switch it is not remembered: a Reset or a tier switch writes the tested setup again, with the recorder off. A content update keeps it, as it keeps any value in the player's own ini.
  - It needs content 2026.10.31 or newer, and it is disabled with the reason while XIV runs or when the ini has no `FgRecorder` line.
  - The mark key (`FgRecorderMarkKey`) has no control in Lucent; the OptiScaler overlay's Keybinds set it.
- **A Recordings row under the switch, shown while the folder exists.**
  - It has the session count, the size, Open folder and **Clear…**.
  - Clear asks first, then deletes only the recorder's own `fg-rec-*` files, and the folder once it is empty; any other file in it stays.
  - It needs XIV closed. Uninstall removes the recordings, as it has since content 2026.10.31.
- **Diagnostics and the bug report.**
  - Copy diagnostics has a `FG recorder:` line: on or off, then the session count and the newest session with its file count and size.
  - The GitHub issue template asks for the newest recording, zipped, when the problem is with frame generation.
- **Settings is tidied.**
  - The groups now run Launch XIV with, XIVLauncher, Updates, Game folder, Game patches, Troubleshooting, Storage, Danger zone.
  - "After a game patch" is now **Game patches**, and its switch carries the same Experimental tag as the Graphics step instead of "(experimental)" in its name.
  - Why changes wait (XIV running, a failed check for it, a missing game folder) is said once, at the top of the page, instead of under each group.
  - Reset setup's button is no longer styled as the page's main action.
  - The page's subtitle names everything it holds.
- **Nothing else changes.** The setup Lucent writes and every other screen are as they were in 1.0.3. No new content version is needed.
