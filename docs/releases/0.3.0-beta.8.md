# Lucent 0.3.0-beta.8

- **ReShade screenshots go to `Pictures\FFXIV Screenshots`.** ReShade needs an absolute path there and expands neither `%USERPROFILE%` nor `~`, so the app writes the Pictures folder Windows reports (a redirected one included) into `ReShade.ini` when it installs. Content 2026.10.21 sets it with `{Pictures}\FFXIV Screenshots` in an `ini_set` value. Like the other ReShade defaults it reaches new installs and Reset; an existing `ReShade.ini` keeps the folder it has.
- **Taking over an existing setup no longer copies presets that are identical to the shipped ones.** A preset in the way of a path the content writes was always saved as `<name> (previous).ini` first, even when it was byte for byte the file the content writes there, which left dozens of duplicates (58 on the maintainer's machine). Scan now hashes just those presets and skips the copy on a match; the backup still holds the original and Uninstall restores it. An edited preset still gets its `(previous)` copy.
- **Uninstall removes what the mods generate in folders.** A `generatedFiles` entry can name a folder, taken with everything in it: content 2026.10.21 lists `OptiScaler\hudless-diag`, where the HUD-less diagnostics write a new folder of files on every run. A vanilla Uninstall also removes the folders an old setup left empty (`licenses`, `gshade-presets` and the like); a folder that still holds a file, such as a carried-over preset, stays.

Content 2026.10.21 requires this app version.

## Validation — 2026-10-19

- TypeScript: 858 tests passed, `npm run typecheck` clean. New tests cover a preset identical to the shipped one (not carried, still backed up and restored, an edited one still carried), a generated folder removed with its files, the folders a vanilla Uninstall empties, and `{Pictures}` on install for the default and a redirected Pictures folder and in the baseline an update writes.
- Rust: `Pictures` resolves through `SHGetKnownFolderPath` next to `Documents`.
- ReShade 6.8.0's source was read for the path rules: `base / SavePath` (an absolute path wins), no environment or `~` expansion, and `create_directories` when it saves. Not handled: ReShade's ini reader splits a value at a comma, so a Pictures path that contains one would be cut there.
- The RTX 4090 manual checklist has not been run for this version, nor a real screenshot taken in game.
