# Lucent 0.3.0-beta.9

- **Uninstall no longer deletes a file you put in Lucent's place.** If you had saved your own file at a path Lucent once wrote to, Uninstall could remove it. It now removes only what Lucent wrote and still holds.
- **Settings can change the game folder after you have installed.** A Change… button next to Game folder opens the same picker as the first scan, so a second copy of the game (a Steam copy and an XIVLauncher copy, say) can be managed without uninstalling the first. The other copy's setup stays where it is.
- **Home shows which files drifted.** Behind a Show files toggle, the card lists what is Missing and what is Changed, so after a game patch you can see which files need repair.
- **Open-folder buttons beside the game folder in Settings, the data folder on the Logs screen and the backups in the App uninstall window.** They open Explorer at the folder.
- **Review warns when a drive is short of the space the plan needs,** per drive, before anything downloads. It is a warning only. The reason Install is waiting now sits above the summary instead of below the fold, behind the footer.
- **Versions lists every changelog line of a version,** not only the first.
- **Switching channel can no longer install the wrong release.** After a failed update check (GitHub's rate limit, say), a Beta player who switched to Stable could still be offered, and install, a pre-release. Update now checks the channel again first, and the check itself is compressed so it no longer times out on a slow connection.
- **Uninstalling Lucent is safer.** Keeping the game files no longer fails when a game folder is gone or on an unplugged drive, the reminder to remove the XIVLauncher add-ons is shown before Lucent exits, and a second uninstall window cannot start while Lucent is open.
- **A first install after a Vanilla Uninstall no longer overwrites the readable backup copies that Uninstall kept.**
- **The starter set stays inside its rules.** A download is not followed to a Heliosphere address by a redirect, and Lucent reads your Dalamud settings again just before it writes, so removing a repository in `/xlsettings` while the Mods screen is open cannot leave Penumbra placed where Dalamud will not load it.
- **Windows 11 no longer offers HDR on a wide-gamut screen that is not HDR** (24H2 and later).
- Dozens of smaller fixes across install, uninstall and updating.

## Validation — 2026-10-23

- TypeScript: 1112 tests passed, `npm run typecheck` clean. New tests cover the changes above.
- Rust: 93 tests passed (3 ignored) with `--locked`.
- The release build (`tauri build --no-bundle`, x64) succeeds, and the exe reports 0.3.0-beta.9.
- The release exe was started with `LOCALAPPDATA` and `APPDATA` pointed at a scratch folder and a fake game folder, and driven as far as Review. Install, drift, Repair and Uninstall were not run in the real exe. The open-folder buttons and the blocking of F5 and Ctrl+R while Lucent is installing were not confirmed there either.
- The RTX 4090 manual checklist and the in-game checks have not been run for this version. It was published at the maintainer's request without them.
