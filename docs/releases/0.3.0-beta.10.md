# Lucent 0.3.0-beta.10

- **Two more choices on the Graphics step: UI mode and DLSS-G preset.** On an RTX 40 or RTX 50 card with frame generation on, you can pick the UI mode (Off, Recomposition, or the experimental UI-free) and NVIDIA's DLSS-G preset (Auto, A, B or C). Preset A and C turn UI recomposition off, so they are greyed out, with the reason, while the UI mode is Recomposition, and UI-free is greyed out while HDR is on. The defaults are Recomposition and Auto, and Review and Done name your picks.
- **They reach new installs and Reset, with content 2026.10.24.** An update leaves your `OptiScaler.ini` as it is, so change them in OptiScaler's menu (the preset applies at once, the UI mode after a game restart) or choose again with Settings → Reset setup. An RTX 20 or RTX 30 card is not offered them and gets UI mode Off.
- **The HUD-less diagnostics are off in new installs.** Content 2026.10.24 stops writing a folder of diagnostic files on every run and stops the UI observation running with the UI mode Off. An existing `OptiScaler.ini` keeps its value.

Needs content 2026.10.24. An older Lucent installs the defaults, Recomposition and Auto, and shows no choices.
