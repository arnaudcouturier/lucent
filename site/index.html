Features

What you get on your card

Lucent manages two features: DLSS 5 through OptiScaler, and ReShade with shaders and presets. It detects your graphics card and installs the setup made for it.

Experimental: players haven’t confirmed that setup yet. In Beta: turn on the Beta channel on Scan, or in Settings.

Lucent can manage more than these two. If there’s a tool you’d like it to handle, open an issue.

For every feature

What the manager does

No archives to unpack and no config files to edit.

  • Finds your game

    Game folder, launcher and graphics card. Works with XIVLauncher, Steam and the Square Enix launcher.

  • Backs up first

    Scan lists every file it will replace, such as an old ReShade or GShade. Each one is backed up.

  • Repairs after patches

    Scan checks every file against its hash. If a patch replaced one, Repair puts it back.

  • Updates when you say

    New versions are offered, never forced. Versions rolls back to an earlier one from the cache.

  • Uninstalls cleanly

    Puts back what it replaced and removes what it added. Your own presets and shaders stay.

  • No telemetry

    Open source. Every file it installs is listed with its hash.

First launch

Windows warns on first launch

Lucent.exe is not code-signed, so Windows shows “Unknown publisher” and SmartScreen may stop it with an “unrecognized app” warning. That’s expected. You can verify the file first.

  1. 1

    Verify the file.

    Download from this page or GitHub releases. Run Get-FileHash -Algorithm SHA256 .\Lucent.exe in PowerShell and compare the result with the SHA-256 on the release page. Continue only if they match.

  2. 2

    Choose “More info”, then “Run anyway”.

    More info reveals the Run anyway button.

  3. 3

    Keep your protection on.

    Don’t turn off SmartScreen or Defender, and don’t add an exclusion. If Windows reports a threat, or there’s no “Run anyway”, stop and report it.

FAQ

Common questions

Anything else: open an issue on GitHub.

Does Lucent change my game files?

Only in the game folder, and only after showing you what it will do. Every file it replaces is backed up, and Uninstall restores them. Your own presets and shaders are kept. If Lucent needs the same path as one of your files, Scan lists it and it is backed up first.

What happens after a game patch?

Lucent checks its files every time it opens, and Scan checks them whenever you ask. If a patch replaced one, the status card offers Repair, which restores it from Lucent’s cache.

Can I use ReShade without DLSS 5?

On RTX cards, ReShade is optional and you choose at setup. On Radeon cards it’s always installed with FSR, and on any other card it’s the only thing Lucent installs.

Does it collect any data?

No. Lucent contacts GitHub to check for updates and download content, and sends nothing about you. If you use Mods, Add plugins also downloads the plugins you ticked from their authors’ repositories. Copy diagnostics puts details on your clipboard only when you ask.

Which graphics cards work?

Lucent has a setup for RTX 50, RTX 20/30/40, Radeon and any other card. Features above shows what each one gets and whether its content is published yet.

How do I remove it?

Settings → Uninstall restores your game folder. To remove Lucent itself, use Settings → Apps; it can restore every game folder on the way out.

Do I need XIVLauncher?

No, any launcher works. With XIVLauncher, Lucent can also check your setup when the game starts and repair it after the game closes.

Where are the keys and settings explained?

In the guide. Lucent also shows your current keys under Keys.
