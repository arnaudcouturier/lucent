BEFORE YOU OPEN IT

Windows may pause the first launch.

Microsoft Defender SmartScreen checks the reputation of downloaded apps. A new app or a new build may not have enough download history yet, even when it is signed. You may see an “unrecognized app” warning.

  1. 1

    Check where it came from.

    Use the download above. It comes from Lucent’s GitHub releases, and the file is named Lucent.exe. Continue only if you trust the file and its source.

  2. 2

    Select “More info”, then “Run anyway”.

    In the “unrecognized app” warning, More info reveals the app details and the Run anyway button. Choose it to open Lucent.

  3. 3

    Keep your protection on.

    You don’t need to turn off SmartScreen or Defender, or add an antivirus exclusion. If Windows identifies a threat, or there is no “Run anyway” option, stop and report the warning.
