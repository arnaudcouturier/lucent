Files

Every file Lucent installs

Where each file goes in your game folder, with its size and SHA-256, for every content version and graphics card. Built from the manifest Lucent reads.

  • Named by hash

    On GitHub, each file is stored under its SHA-256. Releases can’t hold folders, and many names repeat across folders, such as the several LICENSE files.

  • Checked on arrival

    Because the name is the hash, Lucent verifies every byte it downloads before anything reaches your game.

  • Stored once

    A file shared by two versions, or two folders, is uploaded once. Updates download only what changed.

To check a file yourself, run Get-FileHash -Algorithm SHA256 <file> in PowerShell and compare it with the hash below. Each hash links to the exact file on GitHub.
