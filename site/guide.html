Lucent guide

Keys, settings and how-to

Setup, the in-game keys for each feature, and what each setting does. The settings below are the RTX 30/40 content, the only tier published so far. Lucent’s Keys screen shows the keys in your own game folder.

01 · How to use it

Setup

  1. 1

    Open Lucent.

    It’s a single portable Lucent.exe. Windows warns on first launch; here’s what to expect. Close XIV first: Lucent never changes the game folder while the game runs.

  2. 2

    Scan.

    Lucent finds your game folder (XIVLauncher, Steam, the Square Enix launcher or the default location; choose it yourself if needed), your graphics card and its tier. If only beta content is available, turn on Beta channel here. If another ReShade, GShade, OptiScaler or GPosingway is there, Scan lists every file Lucent will back up and replace, and the presets it keeps. Show files opens the full list.

  3. 3

    Choose a profile.

    Pick Fidelity, Balanced or Performance (see performance profiles), whether to include ReShade, and whether to add Lucent to the Start menu. You can change the profile any time later.

  4. 4

    Review, then Install.

    Install downloads every file and checks it against its hash, copies the files it replaces to your Backups folder, applies each change through a journal it can undo, then checks every deployed file. If anything fails, your game folder goes back exactly as it was.

  5. 5

    Play.

    Start XIV as usual. No ReShade preset is active until you pick one: press Shift+F2 in game.

Your original files are copied to %LOCALAPPDATA%\Lucent\Backups\<game folder name>\game under their own paths. Lucent also keeps its own hash-checked backups, which is what Uninstall uses.

02 · Keybinds

In-game keys

These are the keys Lucent ships. If you change one in game, the Keys section of Lucent shows your keys as they are now, and what Lucent had set.

OptiScaler
InsertOpen or close the OptiScaler menu: Neural Rendering, upscaling, frame generation and every setting below.
\Neural Rendering on or off, with a small “On / Off” notice. The Keys section shows the binding your installed content ships; some content leaves it unbound.
EndFrame generation on or off.
Page UpShow or hide OptiScaler’s FPS overlay.
Page DownCycle the FPS overlay through its simple and detailed styles.
ReShade
Shift+F2Open or close the ReShade menu, where you choose a preset.
Shift+F3All ReShade effects on or off, to compare with and without.
Print ScreenScreenshot with effects, saved as PNG in the game’s game folder.

Changing a key

OptiScaler: open its menu, then Keybinds. Click an action and press the new key; Esc cancels and Backspace unbinds. OptiScaler takes single keys, not combinations. ReShade: open its menu, then Settings, and set Overlay key or Effect toggle key. Lucent keeps your keys through content updates, unless an update changes that same key.

03 · Settings explained

What Lucent sets, and why

Lucent writes three config files in the game’s game folder: OptiScaler.ini, ReShade.ini and ReshadeEffectShaderToggler.ini. You can change any setting in the OptiScaler or ReShade menu. When content updates, Lucent keeps your change unless the new content changes the same setting; a few settings, marked reset, always return to Lucent’s value.

Performance profiles

A profile is three Neural Rendering settings. Change one by hand and Lucent shows the profile as Custom until you pick one again.

OptiScaler · Neural Rendering [DlssNr]

Enabledtrue
Turns on DLSS 5 Neural Rendering, which redraws detail and light in the upscaler’s image before frame generation sees it. \ toggles it in game.
Passesprofile
How many model layers run one after another. 2 is deliberately stronger and costs about twice the model time of 1.
RunBeforeSRtrue
Runs Neural Rendering on the render-resolution image just before DLSS upscaling, instead of after it. Cheaper, and the upscaler cleans up its result.
ResidualFGprofile
Runs Neural Rendering every other frame and lets NVIDIA frame generation fill in its changes. Faster, with one extra frame of latency and occasional misaligned effects.
ResidualFGApproxCameratrue
Allows the every-other-frame mode to estimate camera movement when the game doesn’t supply full camera data.
SplitFrameWorktrue
For XIV: spreads the every-other-frame work across two frames, which can smooth frame pacing at the cost of one more buffered frame.
PreSRTrailGuardtrue
Limits Neural Rendering’s edits to what the current frame supports, reducing trails behind moving objects.
SpatialCompressionprofile
Keeps full quality in the centre of the screen and spends less of the model’s work at the edges. SpatialCenterX/Y = 50 sizes the centre region and SpatialWorkX/Y = 60 is the share of work kept at the edges.
VitEvery2
Reuses part of the model’s computation every second evaluation. Saves work; can leave slightly stale detail in fast motion.
PassFeedback0.807
How much of one pass’s edit reaches the next when Passes is 2 or more; below 1 it reins the second pass in.
Preset · Style1 · 2
The model’s built-in profile and style: style 2 is cinematic (0 standard, 1 natural). Pass2Preset and Pass2Style set the same for the second pass.
Intensity2.0
How strongly the first pass applies the model’s picture (0 to 2). Pass2Intensity = 1.29 sets the second pass.
LocalStructure · LocalTone1.75 · 1.46
Strength of fine detail and of local light and shade (0 to 2). The second pass uses 0.53 and 1.24.
SkinStructure1.0
Detail on skin (−1 follows LocalStructure). The second pass uses −0.32, softening skin, with Pass2AutoMask on.
SkinProtectiontrue
A colour-based filter that tones the edit down on skin. SkinDetail and SkinColour at 0.75 keep three quarters of it there. Warm scenery can be mistaken for skin.
ColourStrength1.1
How much of the model’s colour comes through, not just its brightness. 0 keeps the game’s hues exactly.
ReversibleMode3
How the game’s HDR-range image is mapped for the SDR-trained model and back (3: hybrid mapping, composed).
WhitePointSource2
Where the model’s white point comes from. 2 measures the scene’s exposure; in XIV it uses the game’s own lighting to keep the result stable.
ScalingDownscaler4
Lanczos3, used only when the model runs above native resolution.
ToggleKey0xDC
The \ key toggles Neural Rendering in game.

OptiScaler · upscaling

Dx11Upscalerdlss_12
XIV is DirectX 11; this runs DLSS through a DX12 bridge, the only DX11 route that can also run Neural Rendering.
RenderPresetOverride · RenderPresetForAlltrue · 11
Forces DLSS preset K for every quality level.
ForcePerfQuality2
XIV picks its own DLSS quality; this answers it with Max Quality, rendering at two thirds of your resolution per axis (1.5×).
MipmapBiasOverride−0.77
Sharpens textures to match the lower render resolution, so they look as crisp as at native.

OptiScaler · frame generation and pacing

[FrameGen] Enabledtrue
Turns frame generation on. End toggles it in game.
FGInput · FGOutputUpscaler · DLSSG
Feeds the upscaler’s frames to NVIDIA DLSS frame generation.
FramerateLimit138
Caps total frames per second, generated ones included, through Reflex. 138 sits just under a 144 Hz display’s refresh. Set 0 to remove the cap.
ForceVsync · SyncIntervaltrue · 1
Forces V-Sync on, presenting at most once per refresh, for even pacing without tearing.
ForceReflex · LatencyFlexMode2 · 2
Settings for fakenvapi, OptiScaler’s Reflex stand-in: force its low-latency mode on, since XIV has no Reflex setting of its own, and pace frames with Reflex frame IDs.
ForceDMFG · FramerateTargetDMFGtrue · 144
Dynamic multi frame generation toward 144 FPS. It needs an RTX 50 card and has no effect on RTX 30/40.
[XeFG]4× · borderless
Settings for Intel’s frame generation, unused while the output is DLSSG.
HudInterpolationtrue
Turns on interpolation for OptiScaler’s Companion nameplate layer, an opt-in feature of this XIV build.

OptiScaler · HDR, menu and logging

FfxivHDRtrue
Expands XIV’s SDR image to HDR10, only when Windows HDR is on for that display; otherwise the game stays SDR. Turn off RTX HDR and Auto HDR with it. PaperWhiteNits = 240, HighlightExpansion = 0.6, Contrast = 1.1, Saturation = 1.05 and Vibrance = 0.25 shape the result.
LoadReshadetrue
OptiScaler loads ReShade64.dll itself, so ReShade doesn’t need to be installed as dxgi.dll.
Scale1.2
The OptiScaler menu’s size.
LogToFilereset
Off. A debug log can pass 100 MB; turn it on only to report a problem. Updates turn it off again.

ReShade ReShade.ini

PresetPathempty
No preset is active until you choose one in the ReShade menu. ReShade remembers your choice, and Lucent keeps it through updates.
EffectSearchPaths · TextureSearchPaths.\reshade-shaders\…
Where shaders and textures load from, relative to the game folder.
SkipLoadingDisabledEffects1
Compiles only the effects your preset uses, so the game loads faster.
PerformanceMode0
Off, so every effect stays adjustable in the menu. On compiles faster shaders with settings fixed.
PreprocessorDefinitionsdepth
Tells depth-aware shaders how XIV stores depth: reversed, not upside down, far plane 1000.
DepthCopyBeforeClears2
Copies the depth buffer before XIV clears it, so depth effects see the right scene.
InputProcessing2
The game gets no keyboard or mouse input while the ReShade menu is open.
ForceShortcutModifiers1
Shortcuts need exactly their modifiers: Shift+F2, not Ctrl+Shift+F2.
TutorialProgress4
Skips ReShade’s first-run tutorial.
ShowFPS2
ReShade’s frame counter shows only while its menu is open.
FontSize13
ReShade’s default size, which it scales to your resolution (2× at 4K). Ctrl + mouse wheel resizes it in the menu.
FileFormat · SavePathPNG · .\
Screenshots are PNG files in the game’s game folder.
[STYLE]ember
Colours the ReShade menu in Lucent’s orange-on-charcoal theme.

Shader Toggler ReshadeEffectShaderToggler.ini

An add-on that hands XIV’s internal buffers to shaders. Its groups provide motion vectors, normals, decal normals, transforms and material data, which effects such as ray-traced lighting rely on, and a UI group that applies ReShade’s effects before the game draws its interface, so the HUD stays untouched. ResourceShim = ffxiv selects its XIV support. No group has a key.

04 · Everyday use

After setup

Status card
The state of your setup: Healthy, Disabled, files that need repair, or an update, with the action it needs.
Scan
Checks every deployed file against its hash. Use it after you’ve changed something, or if the game looks off. If a file is missing or changed, the card offers Repair. It’s on the Healthy card and under Settings → Game folder, and it works while XIV runs.
Repair
Puts back exactly what Lucent deployed, from its cache, downloading only what’s missing. Your own config changes and presets stay. Game patches that replace a file are the usual cause.
Launch XIV
On Home. Starts XIV the way you do: through XIVLauncher if it’s set up for this game folder, through Steam for a Steam copy, or with the Square Enix launcher. The label below the button shows which one it uses. If more than one applies, use the arrow beside Launch XIV to choose, or change it in Settings. Lucent remembers your choice.
In-game keys
The Keys section: every OptiScaler and ReShade key, read from your game folder each time you look.
Enabled
Off leaves Lucent’s files in place but inactive: the game runs as if vanilla. Turn it on again any time.
Performance profile
Switch between Fidelity, Balanced and Performance. Close XIV first; changes apply the next time it starts.
Updates
Lucent checks for new content and app versions when it opens, and Settings → Check now checks again. Nothing downloads until you click Update. Skip stops the announcement. Versions rolls back to an earlier version.
Beta channel
On Scan before the first deployment when beta content is available, then in Settings. Offers beta app and content versions. Leaving Beta changes nothing installed.
XIVLauncher auto-repair
In Settings, if you use XIVLauncher. Lucent checks your setup when the game starts and repairs it after the game closes.
Uninstall
Settings → Uninstall restores every file Lucent backed up and removes everything it added. Your own presets and shaders stay. To remove Lucent itself, use Settings → Apps.

05 · When something looks wrong

Quick fixes

After a game patch
Open Lucent. If the card says files need repair, click Repair. Otherwise click Scan to check every file.
Too slow
Pick Performance, or press \ to compare with Neural Rendering off.
The look is too strong
Try Balanced, choose a lighter preset with Shift+F2, or turn effects off with Shift+F3.
Washed-out colours
With Windows HDR on, turn off RTX HDR and Auto HDR. OptiScaler handles HDR itself.
Still stuck
Help → Report a bug copies diagnostics and opens a GitHub issue. Questions go in a GitHub issue too.
